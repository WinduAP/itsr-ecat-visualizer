# ITSR EtherCAT Architecture Explorer

Peta arsitektur interaktif untuk sistem **ITSR EtherCAT Master** (`itsr_ecat_master`) dan **ITSR EtherCAT Slave Terminal** (`ETHERCAT_SERIAL_TERMINAL`).

## 🌐 Akses Visualisasi Interaktif Langsung
Kunjungi visualisasi live melalui GitHub Pages:
👉 **[https://winduap.github.io/itsr-ecat-visualizer/](https://winduap.github.io/itsr-ecat-visualizer/)**

## 💡 Fitur
- **Zoom & Pan:** Navigasi bebas pada peta hierarki sistem.
- **Pencarian Modul:** Filter cepat komponen (Master, Slave, Motor, dll.).
- **Inspektor Properti:** Klik modul untuk melihat detail port, siklus waktu (1.000 Hz), dan spesifikasi hardware.
- **Desain Netral Bersih:** Palet warna minimalis bergaya TwinCAT tanpa warna neon menyilaukan.
